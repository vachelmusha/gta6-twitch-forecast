Forecasts Grand Theft Auto VI's launch-day Twitch viewers for hours 2 to 24 as a ratio to hour 1. Each hour's ratio is a weighted average over past launches, weighted by unlock style and hour-1 size and shifted so each launch's US-east midnight unlock lands in the same hour, and the quantiles come from leave-one-out errors on those launches, calibrated on the rolling-midnight console ones (backtest/ reruns the comparison).

## Run it

```sh
mkdir -p out && MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out python3 main.py
```
